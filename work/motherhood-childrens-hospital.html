04 · Healthcare platform

Motherhood

Appointments, doctors and locations in one place for parents. I designed and built the full admin panel UI, and integrated a third‑party appointment API, doctor and speciality management and a hospital locator. The hospital was recognised as ET Edge Best Mother & Child Brand 2025.

  • Laravel
  • Admin panel UI
  • Booking API
  • Alpine.js
  • Tailwind

How it came together

  1. 01 · BriefThe problem

    A paediatric hospital needed online appointments, doctors and locations in one place.

  2. 02 · BuildWhat I built

    The full admin panel UI (Alpine.js, Tailwind), a third‑party appointment API, doctor and speciality management and a hospital locator.

  3. 03 · ShipThe result

    The hospital was recognised as ET Edge Best Mother & Child Brand 2025

Tech decisions

LaravelQueues, auth, validation and a clean MVC core — fast to iterate, safe to scale.
Admin panel UIDesigned and built the whole admin experience staff use every day.
Booking APIThird‑party appointment system integrated behind a clean service layer.
Alpine.jsJust enough interactivity in the Blade views — no heavy SPA to maintain.
TailwindOne design language for every screen, quick to adjust with the client.
