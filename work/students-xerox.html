case study

01 · E‑commerce · Printing

Students Xerox

Printing used to mean a queue at the shop. I project‑led this platform from brief to launch — scoped it with the client, ran the timeline, coordinated the team. Upload a document, pick print settings, pay, track it live. Zero to 700+ active users in the first quarter; orders now process 15% faster.

  • Laravel
  • PostgreSQL
  • AWS S3
  • AWS Lambda
  • Alpine.js
  • Tailwind

How it came together

  1. 01 · BriefThe problem

    Students needed to upload, configure and pay for print jobs online — and see exactly where their order was.

  2. 02 · BuildWhat I built

    Project‑led end‑to‑end: an upload pipeline with print settings, payments and live order tracking — scoped, planned and shipped with the team.

  3. 03 · ShipThe result

    700+ active users in Q1 · 15% faster order processing

Tech decisions

LaravelQueues, auth, validation and a clean MVC core — fast to iterate, safe to scale.
PostgreSQLRelational data with strong consistency for orders, statuses and history.
AWS S3Durable file storage so uploads never sit on the app server.
AWS LambdaServerless functions for work that shouldn’t block a web request.
Alpine.jsJust enough interactivity in the Blade views — no heavy SPA to maintain.
TailwindOne design language for every screen, quick to adjust with the client.
