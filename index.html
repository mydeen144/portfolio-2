Laravel · Performance

Kill N+1 queries before they reach production

The slowdown I fix most often in Laravel apps is the N+1 query: a list page runs one query for the list, then one more for every row’s relationship. Twenty orders with a customer and items quietly becomes forty-plus queries.

$orders = Order::with(['customer', 'items.product'])
    ->latest()
    ->paginate(20);

Eager loading with with() collapses that into a handful of queries, no matter how many rows are on the page. To catch the next one early, make lazy loading throw outside production:

// AppServiceProvider::boot()
Model::preventLazyLoading(! app()->isProduction());

Now a missed relationship fails loudly on your machine instead of quietly slowing down your users.

Laravel · AWS S3

Large uploads to S3 without choking your server

When an app takes big file uploads all day, streaming every file through PHP ties up workers and memory. A cleaner pattern: the browser uploads straight to S3 using a short-lived presigned URL that your Laravel app signs.

$client = Storage::disk('s3')->getClient();

$cmd = $client->getCommand('PutObject', [
    'Bucket' => config('filesystems.disks.s3.bucket'),
    'Key'    => 'uploads/' . Str::uuid() . '.pdf',
]);

$url = (string) $client
    ->createPresignedRequest($cmd, '+10 minutes')
    ->getUri();

Return $url to the front end, PUT the file to it, then save only the key in your database. Any heavy processing can run in a queued job, so the web request stays fast however large the file is.

Tailwind · RTL

Arabic RTL in Tailwind without a second stylesheet

For a bilingual English + Arabic app, you don’t need a separate RTL stylesheet. Set the direction once on the html tag from the current locale:

<html lang="{{ app()->getLocale() }}"
      dir="{{ app()->getLocale() === 'ar' ? 'rtl' : 'ltr' }}">

Then use Tailwind’s logical utilities — ms-* / me-* and ps-* / pe-* (margin and padding start/end) — instead of ml/mr and pl/pr, so spacing flips automatically. Keep the rtl: variant for the few things logical properties can’t handle, like mirroring an arrow icon:

<svg class="h-4 w-4 rtl:rotate-180">…</svg>

Test with real Arabic copy early — it wraps differently from English placeholder text, and that is where most layout surprises come from.
